横轴 空 → 假有 → 空 → 妙有（见地）；纵轴 当下 → 未来 / 愿力（取向）。坛经是横轴上的汇流，弥勒是纵轴上的另一极。

怎么回看

建议的读法

先走横轴的弧

核心六部按序读：空·入门 → 见地 → 经典 → 假有·正题 → 空·合龙 → 妙有·圆成。「空 → 假有 → 空 → 妙有」顺着读，否定与肯定的两步才合得上。

坛经放在汇流处读

读完《金刚经》（空）与《涅槃经》（妙有）之后再读《六祖坛经》——它正是把两者在「顿见自性」里接通的汇流点，惠能也正是闻金刚经而悟。

弥勒随时可读

《弥勒六部经》不在空↔有轴上，挂在正交的「未来 / 愿力」轴，讲慈心与希望的心理结构。任何时候想换个维度，都可以读它。

八个独立文件 · 续写

八篇各自独立的 HTML，放进同一文件夹逐个打开（文件名见每张卡片）。用 skills.md 的「读书笔记唐卡式单页」技能换书名 + 选配色，新篇会按它在两轴上的位置自然并入。
